# YODHA RACE // HYROX FORMAT
### Official Athletic Web Application for Yodha Race 2026
**Organized by ASPIRE Student Association (Department of AIML, D.Y. Patil College of Engineering & Technology, Kolhapur) in Powered Partnership with RUGGEDIAN™**

---

## ⚡ Overview
**YODHA RACE** is Western Maharashtra's premier collegiate functional fitness gauntlet inspired by the official HYROX competitive dynamics. The digital platform features:
- **Hardcore Gym / Athletic Arena Aesthetics**: Dark carbon textures, raw steel framing, high-voltage Volt (`#D2F824`) and Electric Cobalt accents.
- **Rogue Digital Wall Timer**: Live event countdown clock to Saturday, 17th October 2026, 11:00 AM IST.
- **Interactive 7-Station Gauntlet**: Full movement specifications, weights, benchmarks, and valid rep standards with dynamic **Male ♂ / Female ♀** switching.
- **Official Athlete Protocols**: Detailed slide-out drawers featuring anatomical telemetry, valid rep standards, and "NO REP" penalty auditing.
- **Race Heat Dispatch & Loadout**: SY & TY (11:00 AM) vs FE (1:10 PM) reporting schedule with interactive equipment loadout checklist.
- **Official Rulebook & Penalty Simulator**: Interactive simulation of time penalties (+5.0s, +10.0s, and DQ).
- **Duo Reservation Portal (₹100 / Duo)**: 3-step assistant, waiver checklist, UPI QR payment modal, and Google Form ledger.

---

## 🏋️ The 7 Functional Stations
1. **Station 01: 50M Sprint** — 50m Explosive Turf Sprint
2. **Station 02: Burpee / Skip Zone** — 15 Chest-to-Floor Burpees (Male) / 50 Speed Rope Skips (Female)
3. **Station 03: Farmer’s Walk** — Dual 24 kg Kettlebells (Male) / Dual 8 kg Kettlebells (Female)
4. **Station 04: Concept2 / Rowing Erg** — 300m Max-Effort Row (Male) / 150m Cadence Row (Female)
5. **Station 05: Sled Push** — 80 kg Loaded Sled (Male) / 60 kg Loaded Sled (Female)
6. **Station 06: Sled Pull** — 60 kg Battle Rope Pull (Male) / 40 kg Battle Rope Pull (Female)
7. **Station 07: Tyre Flip** — 6 Flips Heavy Monster Tyre (Male) / 6 Flips Medium Tractor Tyre (Female)

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm / yarn / pnpm

### Installation
```bash
# Clone the repository
git clone https://github.com/bindagearyan-bit/yodha-race.git

# Navigate to project directory
cd yodha-race

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build
```bash
npm run build
```
